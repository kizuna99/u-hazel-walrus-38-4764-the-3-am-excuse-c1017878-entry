A single-line excuse from a hardware wallet that refuses to sign at 3 AM: it demands a countersignature from tomorrow-you — who is asleep, and whom it trusts more at that hour.

## Run

```sh
python3 main.py   # writes the line to /output/entry.txt
```

Set `ENTRY_OUTPUT` to override the output path for local runs.
